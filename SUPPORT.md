# Support

Use [GitHub Issues](https://github.com/hamdrew/weather-story-bot/issues) for
public usage questions, documentation corrections, and feature requests.

For vulnerabilities, follow [SECURITY.md](SECURITY.md), not a public issue.
This volunteer-maintained project is not an emergency weather-alerting service;
use official National Weather Service channels for urgent weather information.

Never share tokens, credentials, private IDs, invite links, personal data, raw
payloads, or unbounded operational logs in support requests.
